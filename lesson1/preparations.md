# How to get ready for the course?


1. Install VS Code. Add some plugins.
2. Go to Github.com and create an account
3. Search for Github Education and obtain student benefits.
4. Create a project (just a folder) and open it in VS Code.
5. Write simple HTML (as in example)
6. Open it in your browser, make some changes in the code, see if it works.
7. Install fresh version of: Node.js and NPM (will be installed with node)
8. Check that node works:

```bash
node -v
npm -v
```
