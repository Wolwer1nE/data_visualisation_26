## Choose a project

1. Select a topic from your field of interest that you would like to explore further. 
2. The project should involve data visualization and analysis, and should be feasible to complete within the given timeframe (end of the semester).
3. The project should use at least one external data source (e.g., API, dataset, etc.) and should include at least one interactive visualization.   
4. The suggested topics include, but are not limited to:  
   - Science and technology data 
   - Climate change and environmental data
   - Social media trends and sentiment analysis
   - Health and wellness data
   - Financial and economic data
   - Sports analytics
   - Education and learning analytics
5. The base library should be a React, but you may use other libraries or frameworks. Javascript is the preferred programming language, but you may use other languages as needed.
6. Suggested tools and libraries for data visualization include D3.js, Plotly, Chart.js, and Leaflet.js. You may also use other libraries or frameworks as needed.
7. Write a one-page proposal that includes the following information:
   - Project title
   - Project description
   - Data source(s) and how you plan to use them
   - Proposed visualizations and interactivity
   - Timeline for completion

   Score: up to 5 points for the proposal.
   Deadline: **Oct 22**.
